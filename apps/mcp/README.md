# Sentinel Forge MCP server

**Status: NOT IMPLEMENTED.** Planned for GATE 7.

An optional, read-only Model Context Protocol server exposing recorded findings
to an MCP client.

It will not edit files, execute commands, restart or delete resources, install
software, modify server configuration, or send anything to a remote service.

The full planned contract is in [`docs/MCP.md`](../../docs/MCP.md).

This directory is a placeholder and is not registered as a workspace.
